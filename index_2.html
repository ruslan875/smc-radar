Проверенный бэктестом сетап (CHoCH + Ордерблок+FVG, широкий стоп) детектит и присылает только сам бот в Telegram — сюда он не дублируется, чтобы не разойтись с тем, что реально торгуется. Здесь только общая картина для твоего ручного скрининга.

Score 0-10 и разбивка по факторам — инструмент ручного скрининга, НЕ бэктестенный сигнал. Высокий Score значит "стоит посмотреть глазами", а не "открывай сделку". В режиме топ-50/топ-100 первый скан идёт по всему списку и может занять до минуты — дальше обновляется реже, чтобы не перегружать API Bybit.
Публичные данные Bybit: топ движения за 24ч среди ликвидных USDT-перпов, фандинг по BTC/ETH и текущие торговые сессии. Не сигнал — просто общая картина рынка.

Не сигналы, а дисциплина: серия убытков подряд, сколько от недельного риск-бюджета уже потрачено, и насколько последняя сделка крупнее твоего обычного размера. Считается отдельно по каждой подключённой бирже (плюс журнал, если биржи не настроены) и публикуется ботом автоматически каждые 15 минут — переключайся между источниками ниже, если их несколько.

Ордер уходит через тот же механизм, что и добавление ключей: приложение собирает команду боту, ты проверяешь её в открывшемся чате и жмёшь отправить — бот исполнит ордер на бирже в течение нескольких секунд. Тапнуть кнопку здесь = открыть готовый чат, а не мгновенную сделку (у Mini App нет своего сервера, который мог бы сделать это мгновенно, не раскрывая торговый ключ). Stop-loss обязателен, плечо и недельный риск-бюджет бот проверяет сам перед отправкой ордера на биржу — сделка не пройдёт, если что-то из этого нарушено.

Введи символ, чтобы увидеть график
Открывать только по сигналу Бот откажет, если по символу сейчас нет свежего подтверждённого SMC-сигнала в ту же сторону
⏳ При включённом переключателе бот перед исполнением проверит, есть ли по этому символу свежий подтверждённый сигнал в нужную сторону — если нет, сделка не откроется, придёт отказ прямо в чат. Здесь заранее это не видно (у Mini App нет доступа к списку активных сигналов бота) — только в ответе после отправки.

Ключ уходит боту через чат Telegram, а не напрямую отсюда — так устроены Mini App, открытые через кнопку меню. Нажми «Отправить боту», проверь команду в открывшемся чате и нажми отправить — бот сохранит ключ и сразу удалит сообщение с секретом из истории. Ключ должен быть только READ-ONLY (без прав на торговлю/вывод).
