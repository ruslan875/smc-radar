Ордер уходит через тот же механизм, что и добавление ключей: приложение собирает команду боту, ты проверяешь её в открывшемся чате и жмёшь отправить — бот исполнит ордер на бирже в течение нескольких секунд. Тапнуть кнопку здесь = открыть готовый чат, а не мгновенную сделку (у Mini App нет своего сервера, который мог бы сделать это мгновенно, не раскрывая торговый ключ). Stop-loss обязателен, плечо и недельный риск-бюджет бот проверяет сам перед отправкой ордера на биржу — сделка не пройдёт, если что-то из этого нарушено.
Это ОТДЕЛЬНЫЙ ключ от read-only ключа на вкладке «Настройки» -- тот только читает историю сделок для «Здоровья» и не может торговать. Здесь нужен НОВЫЙ ключ с биржи с правами Trade/Orders и ОБЯЗАТЕЛЬНО без прав на вывод/перевод средств. Без этого ключа `/trade` и автопилот ниже работать не будут.

Команда скопирована в буфер обмена. Если чат с ботом не открылся сам — открой его вручную, вставь команду в поле сообщения и нажми отправить.
Если позиция ушла в прибыль на настроенный порог (по умолчанию +1R), бот САМ переставит стоп-лосс в безубыток — без запроса подтверждения здесь. Это единственное действие в этом боте, которое выполняется полностью автоматически. Стоп можно только подтянуть ближе к цене входа, никогда не отодвинуть — открыть новую позицию или изменить объём автопилот не может. Частичная фиксация прибыли автопилотом НЕ делается — по этому боту приходит только совет в чат, решение и действие всегда твои.
Проверить текущий статус: отправь боту /autopilot без аргументов.
Как только по монете из «Мои монеты» (вкладка «Настройки») срабатывает настоящий подтверждённый сигнал бота — тот же, что проверяет переключатель «Открывать только по сигналу» выше, а НЕ Score из «Скринера» (он ничем не подтверждён, см. предупреждение на той вкладке) — бот сам откроет сделку на указанную ниже сумму и плечо, со stop-loss и take-profit прямо из сигнала. Без запроса подтверждения здесь.
⚠️ Автоторговля игнорирует настройку «Что сканировать» — даже если там выбран топ-50/100, сделки открываются ТОЛЬКО по монетам из «Мои монеты», потому что только на них сигнал реально проверен бэктестом. Сигналы по остальным монетам по-прежнему видны в «Скринере», но сделку по ним автоторговля не откроет.
Пока открыто столько сделок, новые сигналы ждут — бот не откроет сверх этого числа, даже если сигналов больше.
Проверить текущий статус и параметры: отправь боту /autotrade без аргументов.
Ключ уходит боту через чат Telegram, а не напрямую отсюда — так устроены Mini App, открытые через кнопку меню. Нажми «Отправить боту», проверь команду в открывшемся чате и нажми отправить — бот сохранит ключ и сразу удалит сообщение с секретом из истории. Ключ должен быть только READ-ONLY (без прав на торговлю/вывод).
